# Frem – Offline Music Player

A modern offline music player built with **Kotlin and Jetpack Compose**. Inspired by Musicolet, Frem aims to deliver a clean, intuitive, and feature-rich music listening experience with powerful playback controls, library management, and a beautiful user interface.

### Tech Stack
- Kotlin
- Jetpack Compose
- Material 3
- AndroidX Media3 / ExoPlayer
- Room Database
- MVVM Architecture
- Kotlin Coroutines & Flow

### Features
- Local music library scanning
- Songs, albums, artists, and folders
- Background audio playback
- Custom playlists and favorites
- Playback queue management
- Shuffle and repeat modes
- Album artwork
- Mini-player and full-screen player
- Media notifications and lock-screen controls

**Frem — Your music, your way.**
